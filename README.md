# Library Automation Tool

## Project Overview

The Library Automation Tool is a Python-based application designed to manage basic library operations.

It demonstrates Python development concepts such as modules, functions, input validation, data processing, file handling, and error handling.

## Features

- Add new books
- Search books
- Issue books
- Return books
- View all books
- Input validation
- Duplicate Book ID checking
- Error handling
- JSON data storage

## Technologies Used

- Python
- JSON
- Python Modules
- File Handling
